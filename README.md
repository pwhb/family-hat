# 🎩 Family Hat

A dynamic, interactive family tree visualizer built with SvelteKit.

🌐 **Live Demo:** [https://family.avocadao.com/](https://family.avocadao.com/)

---

## 🚀 Getting Started Locally

Follow these steps to set up the project and run the development server on your machine.

### 1. Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed (v20 or higher is recommended).

### 2. Installation

Clone the repository and install the required dependencies:

```bash
git clone [https://github.com/pwhb/family-hat.git](https://github.com/pwhb/family-hat.git)
cd family-hat
npm install
```

### 3. Run the Development Server

Start the local server with hot-reloading:

```bash
npm run dev
```
